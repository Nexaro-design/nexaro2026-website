Deployment Instructions:
✓ Vercel / Netlify (Recommended):
1. Copy all .html files to root 2. Copy nexaro-3d-logo.html to root 3. Copy _headers to root (Vercel/Netlify auto-reads this) 4. Deploy via git push or drag-drop
⚠ Apache Server:
1. Copy all .html files to public_html or web root 2. Rename htaccess-security-block.txt to .htaccess 3. Place .htaccess in web root 4. Verify mod_rewrite is enabled in Apache config

7. Common Customizations

Update Company Name:

Search & replace in all .html files:

Find: "NEXARO GLOBAL" Replace: "[Your Company]" Also update: - <title> tags - Meta descriptions - Schema.org @type and name
Change Colors:

Modify CSS variables at top of each page's <style> block:

#nexaro-root { --navy: #NEW_COLOR; --gold: #NEW_ACCENT; ... }
Update Contact Form:

Form endpoint in index.html (search for form action):

<form action="YOUR_FORM_BACKEND_URL"> ... </form> Or use third-party service (Formspree, Basin, etc.)
Add New Service Card:

In services.html, duplicate one card block and update:

<div class="svc-card"> <div class="svc-num">05</div> <h3>New Service Title</h3> <p>Service description here...</p> </div>

10. Support & Troubleshooting

Issue: Mobile nav doesn't display correctly

Solution: Clear browser cache (Ctrl+Shift+Del or Cmd+Shift+Del). Verify viewport meta tag is present in <head>.

Issue: 3D logo doesn't load on about.html

Solution: Check that nexaro-3d-logo.html is deployed in the same directory. Verify cdn.jsdelivr.net is not blocked by CSP headers.

Issue: Form doesn't submit

Solution: Update form action URL in index.html to your backend endpoint. Test with a POST request in browser console.

Issue: Navigation links return 404

Solution: Ensure all .html files are deployed in the root directory. Verify no URL rewrites are conflicting.
